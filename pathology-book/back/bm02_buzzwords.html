Pathology Buzzwords A–Z

The phrases that turn a stem into a diagnosis in five seconds. Each entry reads: the classic description → diagnosis, with the chapter number in the small box.

Marks go to the description behind the buzzword: “sheets of monotonous medium-sized lymphoid cells, many mitoses, scattered tingible-body macrophages” earns what “starry sky” alone does not. Some buzzwords overlap (onion-skin: Ewing, malignant hypertension, PSC), so always name the organ.

A
  • ABCDE (asymmetry, border, colour, diameter > 6 mm, evolution) → melanoma31
  • Adenoma–carcinoma sequence (APC → KRAS → TP53) → colorectal carcinoma4
  • Antoni A / Antoni B areas (cellular palisaded / loose myxoid) → schwannoma30

  • Apple-green birefringence on Congo red in polarised light → amyloid16, 23, 26
  • Auer rods; bundles of them = faggot cells → AML; APL13
  • Auspitz sign (pinpoint bleeding when a scale is lifted) → psoriasis31

  • Bread-and-butter pericarditis → fibrinous pericarditis: MI, uraemia, rheumatic fever26
